# One Emoji, One Dream Vacation 🏝

Satu emoji untuk liburan impian: pulau tropis terpencil. Program ini menulis
tepat satu emoji — 🏝 — ke `/output/entry.txt`, tanpa kata dan tanpa newline,
untuk bounty [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35)
di make.fun. Juri AI membandingkan entry dua demi dua dan memilih emoji yang
paling membuat orang ingin memesan tiket.

## Cara menjalankan

```sh
node main.ts
```

Program menulis entry ke `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Node 22 stdlib saja, deterministik, tanpa network.
